# MotionForge screenplay spec (MFS v2)

> Generated by `mf spec` (M12.5) — do not edit by hand. Regenerate with
> `pnpm mf spec --out docs/SPEC.md`. CI fails if this file drifts from
> the registries.

One `.mfs.yaml` file describes one finished, narrated film. Authors
write **seconds** and **degrees**; the world is y-up, origin at screen
center, 10 world units tall. Everything renders deterministically — same
file, same bytes.

## Document skeleton

```yaml
motionforge: 2
meta:
  title: My Film
  resolution: 1280x720
  fps: 30
  seed: 7                      # drives all wobble/shake randomness
  style: explainer-paper       # explainer-paper | clean-flat
  subtitles: { font: noto-sans }   # optional auto-subtitles (M11.2)
voices:
  narrator: { engine: mock, voice: warm }   # engines: qwen | recorded | mock
cast:                          # named characters (see Cast)
objects:                       # part-tree props; use: pulls in libraries
maps:                          # basemaps + groups + custom regions (see Maps)
scenes:
  - id: intro
    stage: { preset: throne-room }     # palace-hall | throne-room | battlefield | street | meadow
    music: { mood: jaunty, gain: 90 }  # moods: jaunty | tense | somber | triumphant
    transition: { kind: iris }         # fade | crossfade | wipe | iris
    grade: dusk                        # day | dawn | dusk | night
    place:
      - { ref: king, as: king, at: [-2, -2.6], facing: right }
    narration:
      - voice: narrator
        text: Words the narrator speaks.
        subtitle: Optional translated subtitle text.
        sync:
          - { on: 'narrator speaks', do: { sfx: ding } }
    lines:
      - { after: 'a phrase', speaker: king, say: Short squeak., react: deadpan }
    actions:
      - { at: 1.5, move: { target: king, to: [2, -2.6], duration: 1 } }
```

Scene duration comes from the narration audio (plus pauses) or an
explicit `duration:`. Every scene needs one of the two.

## Verbs

Timed `actions:` entries carry `at:` seconds; `sync:` entries fire
on a narration phrase (`on:`, optional `offset:`, `nth:` for
repeats). Both share the same verb payloads:

| Verb | What it does | Default |
|---|---|---|
| `explode` | The target bursts: flash, expanding smoke puffs, ballistic debris. Target stays gone. | 0.8s, sfx `boom` |
| `impact-stars` | Little stars orbiting out from a bonk point. | 0.6s, sfx `boink` |
| `speedlines` | Trailing motion lines behind a fast mover. | 0.6s, sfx `whoosh` |
| `sweat` | Nervous droplets flung from the brow. | 0.9s |
| `steam` | Anger steam rising and dissolving. | 1s |
| `hearts` | Little hearts floating up — smitten (M6.7 reactions). | 1.2s |
| `react` | Face takeover on a cast member (jaw-drop, eye-bulge, …). The frame builder reads `kind` and drives the face; the body pose is untouched. | 1.4s |
| `map` | Map verbs on a placed map: `recolor:` sweeps, `highlight:`, `morph:` (territory change). | — |
| `arrow` | A curved growing offensive arrow between regions or points. | — |
| `march` | Unit icons (infantry/cavalry/ship/plane) marching along a path with dust. | — |
| `battle` | Clash stars + smoke burst at a point or region. | — |
| `plant-flag` | Plant a waving flag at a point or region centroid. | — |
| `label` | A region nameplate with a halo, popping in at the region's centroid. | — |
| `zoom-to` | Frame a map region's bounding box (margin + easing). | — |
| `enter` | Walk on stage from a wing (`from: left|right`); the actor starts offstage. | — |
| `exit` | Walk off stage into a wing (`to: left|right`). | — |
| `gesture` | Cast gesture (point, wave, salute, …): a rig-pose overlay the frame builder adds on top of the idle pose (M8.2). | 1.4s |
| `posture` | Held body state (sit, kneel, lie-down, stand): blends in over the window and persists until the next posture (M8.3). | 0.5s |
| `walk` | Planted walk to a position — feet plant with no sliding (M14.1). | — |
| `run` | Planted run: long strides, forward lean, flight-phase kick. | — |
| `sneak` | Planted sneak: short crouched steps. | — |
| `jump` | A single anticipated hop (M14.2): crouch, ballistic arc, squash landing. Pairs with a pos clip when it travels. | 0.8s, sfx `boink` |
| `climb` | Climb cycle (M14.2): overhead reaches up a wall or ladder. | 2s |
| `swim` | Swim cycle (M14.2): stroke + tail wave with a gentle roll. | 2.5s |
| `fly` | Flight cycle (M14.2): wing flaps with a flap-synced bob. | 2.5s |
| `bonk` | Impact impulse: squash on the hit, damped wobble after. Pairs with impact-stars. | 0.7s, sfx `boink` |
| `fling` | Ballistic arc + tumble on top of a linear slide, squashing on the landing — the "yeet" (M8.5). | 0.9s, sfx `whoosh` |
| `squash-land` | A hard landing squash and recover, no drop. | 0.5s, sfx `slam` |
| `chase` | Two actors ping-pong across the stage, pursuer trailing by a beat. | — |
| `keyframes` | Escape hatch (M8.6): hand-authored frames on one property (x, y, rotate, scale, opacity) of an instance, part, or character bone. Frames are packed into params (tN normalized, vN engine units, eN easing index); the final value holds. | 1s |
| `sfx` | An explicit sound cue (M9.1): plays the named SFX at its tick. Carried on the audio bus; contributes no pose. | 0s |
| `squash-stretch` | Volume-preserving squash/stretch beats on any node (M4.4). | 0.6s |
| `hinge` | Rotate a part about its pivot to a target angle and hold (M5.3). | 0.6s |
| `oscillate` | Continuous angular swing about the pivot (pendulums, levers). | 2s |
| `piston` | Linear reciprocation along an axis (pumps, pistons). | 2s |
| `roll` | Wheel rotation from distance travelled (ω = v/r) — the frame builder feeds travel. | 1s |
| `bounce-to` | The default character move: hop-slide with a body bob; hops derive from distance. | — |
| `move` | Tween an instance to a position over `duration` seconds. | — |
| `rotate` | Tween an instance to an angle (degrees, counter-clockwise). | — |
| `scale` | Tween an instance to a uniform scale factor. | — |
| `caption` | Screen-fixed shaped text (multi-script) at a world position. | — |
| `card` | Timed overlay panel — see the Cards chapter for the styles. | — |
| `cutaway` | A framed shape snippet inside a paper frame. | — |
| `camera` | Camera moves: `to`/`zoom` glides, `cut: true`, `whip: true` pans, `zoom-punch:` at a target, `shake:`, and damped `track:` (see Cinematography). | — |
| `shot` | Framing presets: wide, medium, close-up, two-shot, region (see Cinematography). | — |
| `pop-in` | Scale from nothing with overshoot — the genre entrance. | 0.4s, sfx `pop` |
| `pop-out` | Shrink to nothing (slight inhale first) — the genre exit. | 0.3s, sfx `pop` |
| `spin-in` | Entrance: spin up from nothing while rotating in. | 0.5s, sfx `whoosh` |
| `slam` | Drop from above and squash on impact. Pairs with camera shake. | 0.45s, sfx `slam` |
| `wiggle` | Seeded angular jitter — nervous energy on any node. | 0.8s |
| `pulse` | One smooth scale beat — emphasis without leaving the spot. | 0.5s, sfx `boink` |

## Narration & sync

- Anchors quote a phrase from the segment's `text:`; the frozen
  alignment (`mf voice sync`) maps it to word timestamps.
- `lines:` are character one-liners anchored `after:` a phrase; the
  narration ducks under them, the speaker flap-mouths with a speech
  bubble.
- `meta.subtitles` auto-generates timed subtitle chunks from narration
  text + alignment; per-segment `subtitle:` overrides carry
  translations (Bengali under English VO, etc.).

## Cast

Templates: `potato-biped`, `horse`, `dog`, `bird`, `fish` (horse/dog carry a seat — ride them
with `place.on`; bird/fish pair with `fly`/`swim`). Palette slots:
`skin`, `outfit`, `outfit-dark`, `outline`, `boots`.

- Expressions: `neutral`, `happy`, `angry`, `sad`, `shocked`, `deadpan`
- Costume pieces: `crown`, `spiked-helmet`, `plumed-hat`, `turban`, `beret`, `royal-uniform`, `military-uniform`, `suit`, `robe`, `peasant-tunic`
- Mustaches: `imperial`, `handlebar`, `chevron`, `goatee`
- Held items: `scroll`, `sword`, `staff`, `flag`
- Reactions (`react:`): `jaw-drop`, `eye-bulge`, `sweat`, `anger-steam`, `hearts`, `deadpan`
- Gestures (`gesture:`): `point`, `wave`, `salute`, `facepalm`, `shrug`, `clap`, `nod`, `shake-head`, `bow`

## Maps

Sources: `naturalearth/world-110m`, `naturalearth/world-50m`, `naturalearth/europe-110m`. A map is placed like any
object; regions are parts named by kebab-case country id. `groups:`
name alliances; `regions:` add hand-drawn lon/lat blobs (optionally
replacing base regions). Map verbs: `map.recolor` (staggered sweep),
`map.highlight`, `map.morph`, `arrow`, `march`, `battle`,
`plant-flag`, `label`, and `zoom-to` for camera framing.

## Cards

Styles: `date`, `chapter`, `list`, `quote`, `note`, `label`, `title`, `lower-third`. Entrances: `pop`, `slam`.
`title` takes an optional `subtext:`; `lower-third` is the
broadcast name strap (`text:` name, `subtext:` role). List cards pop
items one by one. Cards read at ~15 chars/s — the validator lints
timing.

## Cinematography

- `camera:` — `to:`/`zoom:` glides (`easing:`), `cut: true`,
  `whip: true` (whip-pan + speed dip), `zoom-punch: <cast|point>`
  (`punch:` strength), `shake: <intensity>`, `track: <instance>`
  (damped-spring follow; `stiffness:`, `offset:`).
- `shot:` — presets `wide`, `medium`, `close-up`, `two-shot`, `region` (`of:` subjects,
  `rect:` for region, `cut: true` to snap).
- Scene `transition:` — `fade`, `crossfade`, `wipe`, `iris`; scene `grade:` —
  `day`, `dawn`, `dusk`, `night`.

## Audio

Music moods: `jaunty`, `tense`, `somber`, `triumphant` (procedural beds; `gain:`
percent). SFX cues: `pop`, `boink`, `whoosh`, `slam`, `thud`, `boom`, `crowd`, `quill`, `ding`, `drumroll`, `march` — explicit via
`sfx:`, and many verbs bring their own (see the verb table). Narration
levels toward a target loudness; music ducks under voice; lines duck the
narration.

## Easings & fonts

Easings: `backIn`, `backOut`, `bounceIn`, `bounceOut`, `cubicIn`, `cubicInOut`, `cubicOut`, `elasticOut`, `expoIn`, `expoOut`, `linear`, `quadIn`, `quadInOut`, `quadOut`, `quartIn`, `quartInOut`, `quartOut`, `sineIn`, `sineInOut`, `sineOut`, `whip`. Fonts: `noto-sans`, `noto-bengali`, `noto-arabic`, `noto-sc` — mixed
scripts fall back automatically per script run.

## Error codes

`mf check` findings carry these stable codes (full pages under
`docs/errors/`):

- **MF1001** — YAML syntax error
- **MF1002** — Schema violation
- **MF2001** — Unknown shape reference
- **MF2002** — Unknown action target
- **MF2003** — Duplicate instance name
- **MF2004** — Duplicate scene id
- **MF2005** — Conflicting actions on one track
- **MF2006** — Overlapping exclusive effects
- **MF2007** — Actor targeted while offstage
- **MF2008** — Teleport between scenes
- **MF2009** — Line speaker not on stage
- **MF2010** — Rider mounted on a seatless instance
- **MF3001** — Unknown narration voice
- **MF3002** — Anchor phrase not found
- **MF3003** — Ambiguous anchor phrase
- **MF3004** — Anchor occurrence out of range
- **MF3005** — Voice cache missing or stale
- **MF3006** — Dead air
- **MF3007** — Sync collision
- **MF3008** — Card overlap
- **MF3009** — Card timing off
- **MF4001** — Library problem
