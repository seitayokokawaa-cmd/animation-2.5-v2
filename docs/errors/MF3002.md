# MF3002 — Anchor phrase not found

*Family: narration.*

A `sync.on` / `lines.after` phrase does not occur in the segment's narration text, so it cannot be timed.

## Example

```yaml
text: The empire collapsed.
sync:
  - { on: the kingdom, do: { sfx: slam } }   # says "empire"
```

## Fix

Quote a phrase that actually appears in the text — the finding suggests the closest wording.
