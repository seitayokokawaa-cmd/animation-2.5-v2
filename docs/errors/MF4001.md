# MF4001 — Library problem

*Family: libraries.*

A `use:` library file is missing, unparseable, or collides with names defined in the film.

## Example

```yaml
use: [library/porps.yaml]   # typo — no such library
```

## Fix

Fix the path (built-ins live under `library/…`), repair the library file, or rename the colliding object.
