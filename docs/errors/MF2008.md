# MF2008 — Teleport between scenes

*Family: continuity.*

Consecutive scenes on the same stage place the same instance more than 1.5 world units apart, with no exit, enter, or transition to motivate the jump.

## Example

```yaml
# scene 1 (street): imp ends at [2, -2.6]
# scene 2 (street): imp placed at [-3, -2.6] — teleport
```

## Fix

Match the previous position, move the actor on-screen, use exit/enter, or declare a `transition:` (a cut in time motivates re-blocking).
