# MF1001 — YAML syntax error

*Family: structural.*

The file is not parseable YAML — nothing else can be checked until this is fixed.

## Example

```yaml
scenes:
  - id: intro
     duration: 2   # bad indentation
```

## Fix

Fix the YAML syntax at the reported line/column. Typical causes: inconsistent indentation, a stray tab, an unclosed quote or bracket, or a missing `-` in a list.
