# MF2011 — Item interaction without possession

*Family: continuity (held items).*

A `put:`, `give:`, or `throw:` names an actor who is not holding the item at that moment — either nobody took it, or somebody else is holding it. On screen the item would teleport into the actor's hand.

Attach/detach are timeline events, so the validator replays each scene's interactions in time order and always knows who holds what. Holders reset at scene cuts: a held item must be re-taken after a cut.

## Example

```yaml
actions:
  - { at: 1, give: { target: fox, to: crow, item: bread } } # fox never took it
```

## Fix

Add a `take:` for the actor earlier in the scene, or fix the actor name:

```yaml
actions:
  - { at: 0.5, take: { target: fox, item: bread } }
  - { at: 1.5, give: { target: fox, to: crow, item: bread } }
```
