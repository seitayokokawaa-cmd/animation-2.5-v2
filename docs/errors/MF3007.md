# MF3007 — Sync collision

*Family: pacing.*

Two attention-grabbing events (cards, cutaways, explosions) land within 0.3 s of each other and fight for the eye.

## Example

```yaml
sync:
  - { on: the plan, do: { card: { style: label, text: ONE, duration: 2 } } }
  - { on: the plan, offset: 0.1, do: { card: { style: label, text: TWO, duration: 2 } } }
```

## Fix

Stagger the beats by at least 0.3 s using `offset:` or a later `at:`.
