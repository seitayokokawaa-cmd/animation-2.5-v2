# MF2012 — Item taken while already held

*Family: continuity (held items).*

A `take:` targets an item that is already in someone's hand at that moment — the item would vanish from the current holder's hand mid-scene, which reads as a glitch rather than a hand-off.

## Example

```yaml
actions:
  - { at: 0.5, take: { target: fox, item: bread } }
  - { at: 2, take: { target: crow, item: bread } } # fox is still holding it
```

## Fix

Use `give:` for an on-screen hand-off, or have the holder `put:` (or `throw:`) the item first:

```yaml
actions:
  - { at: 0.5, take: { target: fox, item: bread } }
  - { at: 2, give: { target: fox, to: crow, item: bread } }
```
