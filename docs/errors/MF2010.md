# MF2010 — Rider mounted on a seatless instance

*Family: continuity.*

A placement uses `on:` to ride an instance whose template has no saddle (only `horse` and `dog` templates seat riders). The rider renders standing at its own position instead.

## Example

```yaml
place:
  - { ref: king, as: king, at: [0, -2.6], on: other-guy }   # potato-biped has no seat
```

## Fix

Mount a template with a saddle, or drop the `on:`.
