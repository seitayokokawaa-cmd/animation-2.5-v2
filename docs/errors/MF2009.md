# MF2009 — Line speaker not on stage

*Family: continuity.*

A `lines:` entry names a speaker that is not placed in the scene — the speech bubble and flap-mouth would target nobody, and the line's audio would play over an empty stage.

## Example

```yaml
lines:
  - { after: some phrase, speaker: ghost, say: Hello. }
```

## Fix

Place the speaker in the scene or fix the name.
