# MF2006 — Overlapping exclusive effects

*Family: conflict matrix.*

Two effects from the same exclusivity group (two flings, a fling and a bonk, two postures…) overlap on one target. Effects compose additively, so this renders as a glitch, not a blend.

## Example

```yaml
actions:
  - { at: 0, fling: { target: imp, to: [4, 0] } }
  - { at: 0.3, bonk: { target: imp } }   # imp is mid-air
```

## Fix

Stagger the effects so one finishes before the next starts, or pick one.
