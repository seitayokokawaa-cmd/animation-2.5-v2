# MF3008 — Card overlap

*Family: pacing.*

Two cards occupy the same screen area at the same time.

## Example

```yaml
actions:
  - { at: 0.5, card: { style: label, text: FIRST, duration: 4 } }
  - { at: 2, card: { style: label, text: SECOND, duration: 3 } }   # same default spot
```

## Fix

Delay the second card past the first, or give it its own `at:` position.
