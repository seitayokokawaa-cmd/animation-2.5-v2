# MF3006 — Dead air

*Family: pacing.*

More than 5 s of an explicitly-timed scene passes with no beat — nothing pops, moves, or cuts. The genre wants an event every 2–5 s.

## Example

```yaml
- id: a
  duration: 12
  actions:
    - { at: 0.5, pulse: { target: b } }
    - { at: 9, pulse: { target: b } }    # 8.5s gap
```

## Fix

Add a beat in the gap (a pop, card, camera move, gag) or shorten the scene.
