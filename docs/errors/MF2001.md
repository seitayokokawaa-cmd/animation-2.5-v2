# MF2001 — Unknown shape reference

*Family: references.*

A `place:` entry references a name that is not defined under `shapes:`, `objects:`, `cast:`, or `maps:`.

## Example

```yaml
scenes:
  - id: a
    duration: 2
    place: [{ ref: boxx, as: b, at: [0, 0] }]   # "boxx" is not defined
```

## Fix

Define the name in the right section or fix the spelling — the finding suggests the closest defined name.
