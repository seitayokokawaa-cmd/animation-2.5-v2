# MF2005 — Conflicting actions on one track

*Family: conflict matrix.*

Two verbs tween the same track — an instance's pos/rot/scale, or the camera's pos/zoom — with overlapping time windows. Tracks hold one tween at a time; compile would refuse this film.

## Example

```yaml
actions:
  - { at: 0, move: { target: imp, to: [3, 0], duration: 2 } }
  - { at: 1, move: { target: imp, to: [0, 2], duration: 1 } }   # starts mid-move
```

## Fix

Start the second action after the first ends, shorten the first, or drop one. The hint computes the earliest safe start.
