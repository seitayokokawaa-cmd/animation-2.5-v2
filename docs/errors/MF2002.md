# MF2002 — Unknown action target

*Family: references.*

An action (or a `place.on` mount) targets an instance name that is not placed in the scene.

## Example

```yaml
actions:
  - { at: 1, move: { target: ghost, to: [2, 0], duration: 1 } }
```

## Fix

Target a placed `as` name from this scene's `place:` list, or add the placement. The finding suggests the closest placed name.
