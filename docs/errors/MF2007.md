# MF2007 — Actor targeted while offstage

*Family: continuity.*

An absolutely-timed action targets an actor before its `enter` or after its `exit` — the audience sees an empty stage reacting.

## Example

```yaml
actions:
  - { at: 0.5, gesture: { target: envoy, kind: wave } }   # not on stage yet
  - { at: 2, enter: { target: envoy, from: right } }
```

## Fix

Move the action inside the actor's on-stage window, or adjust the enter/exit times.
