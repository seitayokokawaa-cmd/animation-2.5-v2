# MF2003 — Duplicate instance name

*Family: references.*

Two placements in one scene use the same `as` name — actions could not tell them apart.

## Example

```yaml
place:
  - { ref: imp, as: imp, at: [-2, 0] }
  - { ref: imp, as: imp, at: [2, 0] }   # rename one
```

## Fix

Give every placement a unique `as` within its scene (e.g. `imp-left`, `imp-right`).
