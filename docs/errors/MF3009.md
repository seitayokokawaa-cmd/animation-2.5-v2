# MF3009 — Card timing off

*Family: pacing.*

A card is on screen too briefly to read (~15 characters/second plus a beat), or parks for more than 8 s.

## Example

```yaml
- { at: 1, card: { style: label, text: 'A VERY LONG SENTENCE ON A CARD', duration: 1 } }
```

## Fix

Match duration to text length, or split a long-lived card into shorter ones.
