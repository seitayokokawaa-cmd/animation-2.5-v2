# MF1002 — Schema violation

*Family: structural.*

The YAML parsed, but a field has the wrong type, an unknown key, or a value outside the allowed set.

## Example

```yaml
meta: { title: T, resolution: 640x360, fps: thirty }   # fps must be a number
```

## Fix

Follow the hint — it names the field and the expected type or the allowed values. Unknown keys are usually typos; the finding lists them.
