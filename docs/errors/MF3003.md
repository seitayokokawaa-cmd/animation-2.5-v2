# MF3003 — Ambiguous anchor phrase

*Family: narration.*

The anchor phrase occurs more than once in the segment and no `nth:` picks one.

## Example

```yaml
text: The plan. The plan was the plan.
sync:
  - { on: the plan, do: { sfx: ding } }   # 3 occurrences
```

## Fix

Use `{ phrase: "the plan", nth: 2 }` or quote a longer, unique phrase.
